Jumpstart cuts short vertical video by cutting its transcript. Every word carries its own timecode, so striking one out removes exactly that slice of picture and sound — reversibly, without touching the source file.

The mechanic

One press, three sweeps, one undo

Fillers, false starts and dead air are three different problems with three different detectors. Tighten runs all of them and commits once — so taking it back is a single Ctrl+Z, not an archaeology expedition.

Fillers

Matched by shape, not a word list

“um”, “uhh”, “mmm” are caught by pattern, so length doesn’t matter. Discourse markers — “you know”, “I mean” — are flagged but never cut for you. That’s a voice decision.

False starts

No model involved

When you restart a sentence, the words repeat. Longest-first n-gram matching finds the repeat and keeps the last take. It’s arithmetic on the transcript, not a judgement call.

Pauses

With a floor, learned the hard way

Capping every silence at 500 ms made 65 of 175 cuts freeze the picture longer than the gap they removed. A minimum trim fixed it: 175 cuts became 110, frozen picture 21.2s → 13.3s.

Vertical first

Built for the 9:16 frame

New projects open as a reel. Reframe to YouTube or square when you need to, with zoom and pan over a cover fit rather than letterboxing.

Safe-area guides show where Instagram, TikTok and YouTube put their own furniture over your picture — so a caption you spent ten minutes positioning isn’t hidden behind a username. They’re preview only, never burned in.

Captions are timed against the output, so they follow the cut by construction. Style them — font, size, karaoke highlight, outline, box, position — export as SRT, VTT or ASS, or burn them in.

Also in the box

Push-ins that follow the subject

Mark a region, zoom in for a stretch, with ease ramps at each end. A push-in can track a moving subject using cross-correlation over frames the preview already decoded — no ML model, no service, no GPU.

Studio Sound

Highpass, mud dip, presence lift, de-ess, denoise, gentle compression and EBU R128 loudness — with a tone-matched live preview so you hear it before you commit.

Music that won’t get you a strike

Search Openverse (no key needed) or Jamendo. Non-commercial and no-derivatives licences are excluded, because ducking and trimming a track is a derivative work. Every result carries its attribution.

Bring your own model

Claude, Grok, or local

Claude runs on an API key or a Claude subscription you already pay for. Local models work through Ollama, LM Studio or llama.cpp — auto-discovered, no key at all.

Folder memory

Copy that sounds like your channel

Tell a folder what it’s for once. The same local model wrote “Listen to a silly crow story” without that brief, and “Cheeko’s first try at a rhyming game” with it.

Agent-ready

It can change its own code

A second MCP server exposes tests, git checkpoints, revert and restart — deliberately in a separate process, so an agent that breaks the app still has the tools to fix it.

Privacy

It can run with the network off

On a Mac running macOS 26, transcription happens on the machine — free, no key, and verbatim, which is the part that matters: a transcript that tidied away your “um”s can’t be used to remove them.

Pair that with a local model and nothing leaves the machine at all — cuts, captions, colour, framing, tracking and render are already local. When you do use a cloud transcriber, the audio is the request body: no storage hop, no bucket, no public URL.

Before you ask

What it doesn’t do

This is the section most product pages leave out. These are real limits, stated plainly, because finding them yourself after an afternoon of work is worse.

You can’t type new words
A typed word has no timing, so there’s no audio for it. You can fix a word’s spelling — which fixes the captions — and the editor marks it, so it never pretends the audio changed. Real overdub needs text-to-speech, which isn’t built.
No layered tracks
Several source clips in one sequence: yes, reorder and split them. Parallel video layers: no. It’s a sequence, not a multitrack timeline.
Nothing gets published
It drafts your title, description and hashtags. It does not upload to Instagram, TikTok or YouTube — there’s no platform integration at all.
Filler removal needs a verbatim transcript
Whisper-family models normalise “um” away before you ever see it. The transcribe panel flags a non-verbatim model rather than letting you discover it later.
One person, one machine
State is files plus an in-process cache, so run exactly one instance. Auth is a single shared token with no users, scopes or expiry. That’s right for a personal editor and explicitly not a team product.
Windows and Android are partial
macOS is built and shipping. Windows compiles but is unproven. Android runs the real architecture but needs you to build ffmpeg for it first.
Where it runs

Mac app, browser, or a machine in the corner

As a Mac app shipping

A signed-for-your-machine DMG for Apple Silicon or Intel. Bundles its own ffmpeg and the on-device speech helper, so there’s nothing to install alongside it.

As your own server shipping

Run it on a Mac mini and reach it from anywhere over a private network — same app, same library, from a laptop or a phone. Docker image included.

On Windows unproven

The build config is there and the shell is identical to the Mac one, but no recent build has been verified.

On Android partial

The server runs in-process via nodejs-mobile with a WebView UI. You have to compile ffmpeg for it yourself before it can import or render.
